# Test data

`.pdn` files here are Paint.NET project files, taken from the test data of the pypdn
project (<https://github.com/addisonElliott/pypdn>), which is MIT licensed:

    MIT License
    Copyright (c) 2018 Addison Elliott

They are not generated by this project and are not ours to relicense. They are here as
input for the reader test, and they are the reason the reader is checked against
something outside this repository rather than against its own output.

| file | what it covers |
|---|---|
| `Untitled3.pdn` | 2 layers: a background and "Layer 2" with Additive at opacity 161 |
| `FlattenBlendTest.pdn` | 14 layers, one per blend mode, all opaque except four |

`layerVisibleTest1.png` and `layerVisibleTest2.png` are the reference reader's own decode
of the two layers of `Untitled3.pdn`, and the reader test compares against them pixel for
pixel. The third channel is not compared for layer 2, because the reference stores that
layer with alpha 161 where the layer itself carries alpha 255.
