Paint.QT

A raster image editor for Linux desktops, in C++20 on Qt 6.

Install it from a terminal:

flatpak install --user --noninteractive --from \
  https://rubcut.github.io/Paint.QT/repo/io.github.RubCut.Paint.QT.flatpakref

Or in a software centre: this URL is a flatpakref, which is what GNOME Software and KDE Discover read.
